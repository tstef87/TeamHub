# TeamHub

TeamHub is a collegiate athletic communication and management platform.

## Prerequisites

- Node.js and npm installed

## Installation

From the `TeamHub/` directory:

```bash
./install
```

This installs all dependencies for the app.

## Usage

### Start the server

```bash
./start
```

Starts the app in the background and prints the local URL once it's ready.

### Stop the server

```bash
./stop
```

Stops the running server.

## Logs

While running, output is written to `teamhub.log` in the `TeamHub/` directory.
